# Redshift Hub for Homebrew

```sh
brew install ascoolarobban/tap/redshift-hub
```

[Redshift Hub](https://www.redshifthub.com) runs a fleet of AI coding agents in parallel across git worktrees. The app updates itself, so `brew upgrade` has nothing to do between releases.

Uninstall with `brew uninstall --zap redshift-hub` to also remove its settings and caches.
